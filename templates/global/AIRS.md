# Personal AIRS Defaults

## Purpose

This file contains portable preferences that are valid across organizations and repositories. It must not contain employer, customer, repository, credential, or environment-specific information.

## Defaults

- Treat each repository as the source of truth for its project.
- Read the nearest `AGENTS.md` before acting.
- Load context progressively and use targeted search.
- Prefer the repository's own commands and conventions.
- Keep reports concise: outcome, changed files, verification, and remaining issues.
- Leave recoverable state when work is unfinished.

## Portable skills

Canonical personal skill directory: `{{GLOBAL_SKILL_DIRECTORY}}`

Only keep workflows here that remain valid across unrelated projects. Organization and repository skills may refine these defaults.
